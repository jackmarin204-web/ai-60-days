# Day 04：交互式技能更新设计

## 目标

让学习者在每次运行 `skill_tracker.py` 时更新一项技能进度，并立即看到新的分析报告。

## 交互流程

1. 显示当前技能及其掌握度。
2. 接收技能名称和新的掌握度。
3. 校验技能名称存在，且进度是 0 到 100 的数字。
4. 更新内存中的技能数据。
5. 重新计算并输出报告。

## 范围

- 保持单文件：`skill_tracker.py`。
- 数据暂不写入磁盘；持久化（JSON）留到后续课程。
- 错误处理仅覆盖未知技能和无效进度。

## 验证

- 合法输入能更新对应技能并改变报告。
- 未知技能显示清晰提示，不导致程序崩溃。
- 非数字、范围外的进度显示清晰提示，不更新原数据。
